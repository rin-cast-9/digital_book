# Цифрокнига

## Обзор

Цифрокнига — децентрализованное приложение (dApp), которое позволяет пользователям сохранять и отслеживать книги на блокчейне. Система разработана для обеспечения автоматизации работы книжного приюта. Проект состоит из смарт-контрактов, развернутого на блокчейне, который управляет информацией о книгах, и веб интерфейса для удобного взаимодействия с системой.

## Функциональность

### Система

- **Хранение книг:** Хранение данных о книгах на блокчейне:
    - название
    - издатель
    - город публикации
    - год публикации
    - является ли книга изъятой на данный момент
- **Добавление книг:** Позволяет добавлять книгу в блокчейн
- **Каталог:** позволяет просматривать всю книжную коллекцию

### Веб-интерфейс

- **Панель администратора** для управления ключами
- **Каталог** для просмотра книжной коллекции
    - **Форма для оформления доставки книги** (будет реализовано в будующем)
- **Страница для добавления книги**

## Технологии

- **Etherium-блокчейн**
- **Смарт-контракты:** написаны на языке Solidity
- **Веб-интерфейс:** написан на React

## Использование

### Клонирование репозитория

Сначала необходимо склонировать репозиторий на свой компьютер:
```bash
git clone https://github.com/rin-cast-9/digital_book.git
cd ./digital_book
```

### Локальный запуск

#### Требования

- Node.js (v20+)
- yarn (v1.22+)
- nginx (v1.27.1)

Далее необходим сделать скрипт для запуска исполняемым, и исполнить его:
```bash
chmod +x ./local_launch.sh
./local_launch.sh
```

### Запуск с использованием технологий контейнеризации

#### Требования

Для запуска необходимо что-то одно из списка:

- Docker
- Podman (v5.3.2+)

Далее необходим сделать скрипт для запуска исполняемым:
```bash
chmod +x ./docker_launch.sh
```

Если используется Docker, то запуск будет производиться командой:
```bash
./docker_launch.sh
```

Если используется Podman, то запуск будет производиться командой:
```bash
./docker_launch.sh 1
```

### Пост-запуск

Необходимо дождаться развертывания контрактов на локальной сети блокчейна, это можеть занять до 60 сек. Когда в терминале появится следующее сообщение, то это будет означать что система готова к работе.
```txt
[ DigitalBookModule ] successfully deployed 🚀
```

### Работа с веб-интерфейсом

Далее необходимо открыть браузер и перейти по адресу: `http://localhost:3000`.

Откроется страница каталога, также есть панель навигации сверху. С помощью данной панели можно быстро перемещаться по веб-сайту.

Рассмотрим каждую страницу по подробнее.

#### Панель администратора

Имеет две вкладки:

- регистрация ключей
- управление ключами

Вкладка регистрации позволяет добавлять и отзывать ключи в / из систему(ы).

Вкладка управления ключами сохраняет ключи локально. Это позволит повысить перечень привелегий при работе с сайтом. Ключи также можно добавить и удалить.

Известная проблема: предварительно сохраненные ключи, при отзыве останутся в хранилище без возможности удаления. На данный момент это можно избежать если написать в консоли браузера `sessionStorage.removeItem("<название ключа>")`, где `название ключа` это:
- `adminKey` — ключ администратора
- `operatorKey` — ключ оператора
- `managerKey` — ключ менеджера
- `userKey` — ключ пользователя

#### Каталог

Каталог предоставляет список книг. На любой книгу можно нажать и получить возможность оформить доставку этой книги. После нажатия кнопки "заказать" откроется форма для заполнения. При нажатии кнопки "доставить" книга будет отмечена как изъятая из оборота.

Для оформления доставки необходимо обладать ключом пользователя (иметь роль пользователя).

#### Добавление книги

Страница позволяет заполнить соответствующие данные о книге и добавить ее в блокчейн.

Есть возможность добавление нескольких авторов, для этого необходимо начать вводить в поле автора. После этого появится еще одно поле для ввода. Если был введен ненужный автор, при опустошении поля в середине (между другими полями), оно автоматически исчезнет.

Добавление в блокчейн требует ключа оператора (иметь роль оператора).

## Технические детали

### Контракт

#### Описание

1. **RolesManager** — Контракт для управления ролями пользователей в системе.
    - Этот контракт используется для определения и управления ролями, такими как:
        - **Оператор (OPERATOR_ROLE)** — может добавлять книги.
        - **Менеджер (MANAGER_ROLE)** — может добавлять пользователей (с ролью USER_ROLE).
        - **Пользователь (USER_ROLE)** — может оформлять доставки книг (устанавливать флаг `isAdopted` в `true`).
    - Администратор (DEFAULT_ADMIN_ROLE) имеет доступ к добавлению и удалению ролей для других пользователей.

2. **BookManager** — Контракт для управления книгами.
    - Этот контракт позволяет:
        - Добавлять книги в систему.
        - Получать информацию о книгах.
        - "Заказать" книгу (изменить её состояние на `adopted`).
    - Использует контракт `RolesManager` для управления правами доступа.

#### Структура контракта

1. **RolesManager**:
    - Конструктор: присваивает роль администратора вызвавшему контракту (msg.sender).
    - Функции:
        - `addOperator`: добавляет оператора.
        - `revokeOperator`: удаляет оператора.
        - `addManager`: добавляет менеджера.
        - `revokeManager`: удаляет менеджера.
        - `addUser`: добавляет пользователя.
        - `revokeUser`: удаляет пользователя.

2. **BookManager**:
    - Структура данных `Book`: описание книги (название, издатель, город публикации, авторы, год выпуска, статус изъята / не изъята).
    - Методы:
        - `getBook`: возвращает информацию о книге по её ID.
        - `getBooks`: возвращает список всех книг.
        - `addBook`: добавляет новую книгу в систему.
        - `adoptBook`: позволяет пользователю усыновить книгу (изменить её статус).
    - События:
        - `BookAdded`: случается когда происходит добавление книги в блокчейн.
        - `BookAdopted`: случается когда происходит изъятие книги из оборота.

#### Возможности

1. Администратор может назначать роли другим пользователям через функции контракта `RolesManager`.
2. Операторы могут добавлять книги, а пользователи могут усыновлять книги.
3. Менеджеры могут добавлять или удалять пользователей.
